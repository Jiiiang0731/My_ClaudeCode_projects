## 项目说明

### Tomato_Timer_番茄钟

功能完整的桌面番茄钟应用，采用番茄工作法（25 分钟工作 + 5 分钟短休息）。
支持自动轮换、每日统计、目标管理、提示音、深色主题和快捷键。

详见 [Tomato_Timer_番茄钟/README.md](Tomato_Timer_番茄钟/README.md)。

### Python

Python 学习与练习，包含：

- 面向对象：面向对象编程与数据分析案例；
- Pyspark_basic：PySpark RDD 操作及 Python 进阶（多线程、网络编程、装饰器、设计模式、正则、递归、闭包等）；
- 番茄钟.py：番茄钟桌面应用的独立版本。

### SQL

MySQL 学习笔记与查询练习，涵盖 DDL / DQL / DML、多表操作（联合查询、嵌套查询）、事务、索引、存储过程与函数、触发器、视图、控制流与窗口函数、JDBC、SQL 优化、日志与测试数据等。

### 思维导图

MySQL 学习相关的 XMind 思维导图，包括基本查询、DML 操作、多表操作、约束、视图与存储过程等。

## 使用到的技术

- Python：桌面应用开发、面向对象编程、PySpark 大数据处理
- MySQL：数据库设计、查询、多表关系、索引与存储过程
- PySpark：RDD 操作与大数据处理基础
- XMind：学习笔记与知识整理
