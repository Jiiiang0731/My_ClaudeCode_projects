# 番茄钟 - Pomodoro Timer

一个功能完整的桌面番茄钟应用，帮助您高效管理时间，采用 **番茄工作法**（25分钟工作 + 5分钟短休息）。

## 功能特点

| 功能 | 说明 |
|------|------|
| **番茄计时** | 默认 25 分钟工作 + 5 分钟短休息 + 15 分钟长休息 |
| **自动轮换** | 每完成 4 个番茄自动进入长休息 |
| **日统计** | 记录每日完成的番茄数，自动重置 |
| **目标管理** | 可设置每日目标番茄数，带进度条展示 |
| **提示音** | 番茄完成/休息结束时播放声音提醒 |
| **深色主题** | 舒适的深色界面，圆形进度环倒计时 |
| **快捷键** | 空格=暂停/继续，R=重置，ESC=退出 |
| **自定义配置** | 可自定义所有时长、目标和通知行为 |

## 运行环境

- **Python 3.6+**（推荐 Python 3.10 或更高版本）
- 不需要额外安装第三方库（仅使用 Python 标准库）

### 依赖说明

| 模块 | 说明 | 类型 |
|------|------|------|
| `tkinter` | GUI 图形界面（Python 内置） | 标准库 |
| `threading` | 多线程计时 | 标准库 |
| `winsound` | Windows 系统提示音 | 标准库（仅 Windows） |
| `json` | 配置和统计数据持久化 | 标准库 |
| `os` | 文件路径操作 | 标准库 |
| `time` | 计时 | 标准库 |
| `datetime` | 日期记录 | 标准库 |

> **注意**：`winsound` 模块仅在 Windows 系统上可用。如果您在 macOS 或 Linux 上运行，程序会自动回退到静默模式。

## 运行方法

### 直接运行

```bash
python pomodoro_timer.py
```

### 一键运行（Windows）

双击 `pomodoro_timer.py` 文件即可启动。

## 快捷键

| 按键 | 功能 |
|------|------|
| `Space` | 开始 / 暂停 |
| `R` | 重置计时 |
| `Esc` | 退出程序 |

## 自定义设置

点击界面中的 **设置** 按钮，或在 `pomodoro_config.json` 中直接修改：

```json
{
  "work_time": 1500,          // 工作时间（秒），默认 25 分钟
  "short_break": 300,         // 短休息（秒），默认 5 分钟
  "long_break": 900,          // 长休息（秒），默认 15 分钟
  "long_break_interval": 4,   // 每 N 个番茄后长休息
  "daily_goal": 8,            // 每日目标番茄数
  "auto_start_break": false,  // 完成后自动开始休息
  "sound_enabled": true,      // 启用提示音
  "stay_on_top": false        // 窗口置顶
}
```
