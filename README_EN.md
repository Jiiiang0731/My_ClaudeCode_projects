## Project Descriptions

### Tomato_Timer_番茄钟

A complete Pomodoro desktop timer app (25-minute work + 5-minute short break),
with automatic rotation, daily statistics, goal tracking, sound alerts, a dark
theme, and keyboard shortcuts.

See [Tomato_Timer_番茄钟/README.md](Tomato_Timer_番茄钟/README.md).

### Python

Python learning and exercises, including:

- 面向对象: object-oriented programming and a data-analysis case;
- Pyspark_basic: PySpark RDD operations and advanced Python topics
  (threading, networking, decorators, design patterns, regex, recursion, closures);
- 番茄钟.py: a standalone version of the Pomodoro timer.

### SQL

MySQL learning notes and query exercises covering DDL / DQL / DML, multi-table
operations (joins and nested queries), transactions, indexes, stored procedures
and functions, triggers, views, control-flow and window functions, JDBC, SQL
optimization, logs, and test data.

### 思维导图

XMind mind maps for MySQL learning, including basic queries, DML operations,
multi-table operations, constraints, views, and stored procedures.

## Technologies

- Python: desktop app development, object-oriented programming, PySpark
- MySQL: database design, queries, multi-table relationships, indexes, stored procedures
- PySpark: RDD operations and big-data processing basics
- XMind: study notes and knowledge organization
